# Чат-бот «Учебный ассистент студента»
Проект в рамках курса «Объектно-ориентированное программирование» (2026).

## О проекте
Бот для навигации по расписанию пар и трекинга учебных дедлайнов. Позволяет запрашивать расписание на день/неделю, а также пошагово создавать и отслеживать задачи по предметам. 
В дальнейшем проект переедет в Telegram с кнопочным интерфейсом, получит систему активных фоновых напоминаний (бот сам пишет о приближении дедлайна и утреннем расписании) и интеграцию с API расписания университета.
